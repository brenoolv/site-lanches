# Breno Lanches 🍔

Site de uma lanchonete fictícia, feito com HTML e CSS para praticar desenvolvimento web.

🔗 **Ver o site:** https://brenoolv.github.io/site-lanches/

## O que tem no projeto

- Cardápio com cards alinhados (Flexbox)
- Botão de pedido direto pelo WhatsApp
- Seção de localização com mapa do Google
- Layout responsivo para celular
- Rodapé com contatos

## O que aprendi

Flexbox, seletores e especificidade no CSS, media queries, links e mapas incorporados, e publicação com Git e GitHub Pages.

## Tecnologias

- HTML5
- CSS3
- Font Awesome
- GitHub Pages
